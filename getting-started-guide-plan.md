# Getting-started guide: plan

A visual how-to for new OnionPress users, with real screenshots marked up with circles and arrows showing where to click.

**Output:** first a private web page for review, then the same content as an OnionHome help page, in the format of `onionpress/docs/help-import-twitter.html`.

## Chapters

0. **First launch and setup (placeholder, to do later).** Installing OnionPress, the first-run setup, downloading Brave, and using Tor for the first time. A lot of people haven't done these before. We'll need a fresh setup to screenshot this, so it's being done later.
1. **Find the OnionPress icon** in the menu bar, including where it appears on a two-screen setup.
2. **The OnionPress menu:** what the status line means, plus Open Local Site, Copy Onion Address and Open in Tor Browser.
3. **Get into your dashboard** with **Open Local Site**. Explain that there's no WordPress password: it's a one-time sign-in link that expires after 2 minutes. If you see the WordPress login page, go back to **Open Local Site**.
4. **Write and publish your first post:** the title, the body and the Publish button.
5. **See your site the way visitors do:** Copy Onion Address, then open it in Tor Browser.
6. **Keep a backup** with **Backup…**.
